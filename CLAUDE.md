# Контекст проекта

Это портфолио-сайт **Сергея Ванакова** — продуктового дизайнера с 2 годами опыта. Сайт написан вручную на чистом HTML/CSS/JS, без фреймворков и сборщиков. Всё на русском языке.

## Структура файлов

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница |
| `rytmo.html` | Кейс 01 — фитнес-приложение Rytmo |
| `dash.html` | Кейс 02 — EdTech-сервис Дэш |
| `styles.css` | Единый CSS для всех страниц |
| `my-info.txt` | Текстовый черновик контента (не отображается на сайте) |

## Визуальные и UX-детали

- Шрифт: **Inter** (Google Fonts, variable)
- Кастомный курсор: dot + ring с анимацией следования
- Hover-звук на ссылках и кнопках — **plinq** (`click`), подключён через `https://esm.sh/plinq`, все `<script>` теги имеют `type="module"`
- Параллакс на обложках проектов при наведении
- Зернистость фона (`.grain`)
- Мобильная версия **не адаптирована** — показывается заглушка `.mobile-only`
- Nav-ссылки появляются только после скролла hero-секции (IntersectionObserver)

## Прототипы в кейсах

Блоки `.case-prototype-wrap` содержат оверлей `.proto-overlay` с иконкой руки (Phosphor Icons) и текстом «Интерактивный прототип». Оверлей исчезает при наведении (CSS hover), открывая интерактивный Figma-прототип в iframe.
